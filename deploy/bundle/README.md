# deployer join bundle

Generated by the gateway (Gateway operations › Modules › deployer › Add).

    docker compose up -d

`private/` holds credentials (the single-use enrolment token, the bundle's
TLS keys); `.env` holds generated passwords and the credential key;
`config.yaml` holds the event-bus password you gave. Keep them on this host
only. The enrolment token is valid for the lifetime chosen in the wizard;
after the first start the module renews its identity itself.

The deployer joins the core's event bus (Valkey, TLS) as user `deployer`:
the core's Valkey must accept that user from this host. On the core, lcm's
policy must allow `spiffe://<trust domain>/svc/deployer` to call
`lcm.v1.Certificates/Download`, and auth's to call
`auth.v1.Profiles/ListMembers`. The inventory-agent provider is not
enabled in this bundle.
